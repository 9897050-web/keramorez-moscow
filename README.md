# КЕРАМОРЕЗ — сайт для демонстрации заказчику

Статический адаптивный сайт нового бизнеса по резке керамогранита в Москве. Рабочее название «КЕРАМОРЕЗ» предложено для макета. Контакт предоставлен заказчиком: +7 985 986-25-64.

## Запуск

Открыть index.html либо выполнить `python -m http.server 4186` из папки сайта.
Проверка расчётов: `node calculator.test.cjs`.
Для GitHub Pages: Settings → Pages → Deploy from a branch → main → / (root).

## Калькулятор

Размеры готовой детали в миллиметрах, количество, толщина, стороны обработки, прямой рез / 45° / другой угол, количество отверстий на деталь и диаметр. Несколько позиций, однократное применение минимального заказа, скачивание и копирование расчёта.

Добавленная позиция не считается повторно. Изменение полей создаёт текущую следующую позицию; она входит в живую оценку до сохранения. Нестандартные случаи дают «По чертежу», а не выдуманную точную цену. Данные формы не отправляются на сервер и не сохраняются после перезагрузки.

## Источники и допущения тарифов

Срез 21.10.2026; это предложенный прайс демоверсии, а не подтверждённый коммерческий прайс нового цеха.

- https://plitrez.pro/ : прямой рез от 150 ₽/м, 45° от 450 ₽/м, минимум 2 000 ₽.
- https://plitkarez-mos.ru/ : для формата 120–150 см прямой рез от 250 ₽/м, 45° — 500 ₽/м; отверстия Ø10/50/100/120 мм — 100/500/1000/1200 ₽.
- Граница 1200 мм включена в базовый диапазон, до 1500 мм включительно — увеличенный тариф. Для выбора тарифа используется максимальная сторона готовой детали; исходный материал проверяется отдельно.
- 6–12 мм — принятое консервативное ограничение автоматической оценки, а не проверенный производственный допуск. Другие толщины и формат свыше 1500 мм требуют уточнения.
- Минимум применяется к обработке всего заказа; стоимость материала, доставки, склейки, полировки и монтажа не входит.
- При запиле 45° дополнительная стоимость прямого реза на той же стороне не начисляется. Обе кромки стыка учитываются по отдельности.
